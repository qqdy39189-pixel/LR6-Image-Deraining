# LR6 图像去雨项目

## 一、项目简介

本项目是一个基于 PyTorch 的图像去雨作业，主要研究如何利用深度学习模型去除雨天图像中的雨纹，尽可能恢复清晰的背景图像。

项目包含去雨网络、损失函数、数据处理、模型训练相关代码，以及实验报告和模型可视化结果。

## 二、项目内容

主要文件和文件夹说明如下：

| 文件或文件夹 | 说明 |
| --- | --- |
| `main.py` | 项目的主要程序入口，具体运行流程以代码为准 |
| `dataset.py` | 数据集读取与处理相关代码 |
| `models/` | 去雨网络及相关模型的实现 |
| `losses/` | 损失函数相关代码，包括感知损失等 |
| `utils.py` | 训练或图像处理过程中使用的辅助函数 |
| `requirements.txt` | 项目所需的 Python 依赖库 |
| `Reports/` | 图像去雨任务的学习笔记与实验报告 |
| `output_picture/` | 模型结构、特征可视化等相关图片 |
| `count_params.py` | 模型参数量统计相关代码 |
| `export_onnx.py` | 模型导出 ONNX 格式相关代码 |
| `visualize_features.py` | 模型特征可视化相关代码 |
| `mymodel.onnx` | 导出的 ONNX 模型文件 |

## 三、运行环境

本项目使用 Python 和 PyTorch 开发，建议使用虚拟环境安装依赖，避免与电脑上的其他 Python 项目发生冲突。

开发过程中使用过的环境包括：

- 操作系统：Windows
- Python：3.14.6
- 深度学习框架：PyTorch
- GPU：NVIDIA GeForce RTX 5060 Laptop GPU
- CUDA：使用支持 CUDA 的 PyTorch 版本进行 GPU 计算

以上为开发环境信息。其他电脑的 Python、显卡驱动和 CUDA 支持情况可能不同，需要根据实际环境调整。

## 四、安装依赖

### 1. 下载项目

将本仓库克隆到本地：

```bash
git clone https://github.com/qqdy39189-pixel/LR6-Image-Deraining.git
cd LR6-Image-Deraining
```

也可以在 GitHub 仓库页面下载 ZIP 压缩包并解压。

### 2. 创建虚拟环境

确保已经安装 Python，然后在项目根目录打开终端，执行：

```bash
python -m venv .venv
```

Windows PowerShell 激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

如果终端前面出现 `(.venv)`，说明虚拟环境已经激活。

### 3. 安装依赖

执行：

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

如果安装过程中出现 PyTorch、CUDA 或其他依赖的兼容性问题，需要根据电脑环境调整安装版本。

## 五、运行说明

运行前，请先检查 `main.py` 中的程序入口、数据集路径、模型保存路径和运行参数。

程序需要额外的命令行参数，需要分别运行训练、测试和模型评估。具体情况见main.py

**注意：** 本仓库不包含完整数据集，因此仅下载代码后不能直接开始训练。运行前需要准备符合代码要求的数据，并检查相关路径是否正确。

## 六、数据集与模型权重说明

为了减少仓库体积，本项目没有上传完整数据集和部分模型权重文件。

- **数据集：** 请根据程序要求准备相应的数据集，并按照 `dataset.py` 中的读取方式放置文件。
- **模型权重：**  `.pth`、`.pt` 等权重文件未提交到 GitHub。需要使用已有权重进行测试时，请自行获取对应文件，并放置到代码指定的位置。同时也可自行训练。
- **ONNX 模型：** 仓库中包含 `mymodel.onnx`，可用于后续模型结构查看或 ONNX 推理相关实验。

## 七、学习报告与实验结果
