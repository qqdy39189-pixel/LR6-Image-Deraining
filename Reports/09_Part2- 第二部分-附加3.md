# 1. 开头那句话有道理吗？对比学习一般具有哪些特征？

## 有道理

“这个感知损失变体，感觉和标准的对比学习不太一样吧？”——**有道理，是定义上的差别。**

它**借了对比学习的思想（拉近正样本、推远负样本），但不是标准对比学习的形式**。

## 狭义的“标准对比学习”的特征

以 SimCLR v1、MoCo v1 为原型，一般有下面这些特征：

### 1. 任务是实例判别、无标签表征预训练

每张无标签图像自成一类。目标不是直接输出一张图，而是学一个能区分不同实例、又对同一实例的不同角度保持不变的编码器，预训练完再拿去做下游任务。

### 2. 正样本对来自同一图像的两次随机增强

同一张图做两次随机裁剪、颜色失真、模糊等，得到两个视图，互为正样本。

### 3. 有显式的、大量的负样本

负样本是提供排斥力的关键：没有它，所有表征坍缩成同一个常向量也能让“拉近正样本”这一项看起来完成任务。

### 4. 损失是 InfoNCE / NT-Xent 类的 softmax 辨别形式

带温度 τ 的形式：分子拉近正样本对，分母推远全部负样本。CPC 最早把这个损失命名为 InfoNCE ，SimCLR 把它命名为 NT-Xent。

### 5. 训练对象是编码器本身

对比损失直接训练要被复用的表征编码器，而不是训练一个下游任务网络、把对比当成辅助正则项。

### 6. 要解决“负样本又多又一致”的工程问题

SimCLR 靠大 batch 换负样本数；MoCo 靠队列加动量编码器换一致性；MoCo v3 去掉队列、回到大 batch 内负样本。

## 和标准对比的六处差别（开头那句话的道理）

1. **目标不同**：标准对比是无标签表征预训练，学一个可迁移的编码器；任务变体是有监督图像复原的辅助损失，目标是直接让去雨输出变好，编码器根本不学。
2. **正负样本的定义不同**：标准对比的正样本是同一无标签图像的两次增强，负样本是其他图像；任务变体的正样本是**成对的干净真值**（有监督），负样本是**同一场景的有雨输入**。
3. **负样本的数量和来源不同**：标准对比靠大量负样本提供排斥力；任务变体每样本只有 **1 个正样本 + 1 个负样本**，排斥力只来自那一项 sim_neg。
4. **损失形式不同**：标准对比是 InfoNCE / NT-Xent 的 softmax 辨别；任务变体是两个余弦相似度的线性组合，没有分母、没有温度、没有归一化成概率。
5. **特征处理不同**：标准对比通常在投影后的低维表征上算相似度；任务变体先把 VGG 特征图全局平均池化成 512 维向量再算余弦，**只比方向、不比大小，且丢掉了空间位置信息**。

## 广义自监督里，很多不是“标准对比”

- **无负样本路线**：BYOL、SimSiam、DINO它们靠不对称结构、慢目标、分布约束代替负样本的排斥力。
- **聚类路线**：SwAV 不直接比较两张图的特征，而是同时做在线聚类，强制同一张图不同视图的聚类分配一致。它保留了“同图一致、不同图区分”的对比思想，但没有显式成对负样本。
- **前身 / 平行路线**：CPC（上下文 vs 未来）、NPID（自身身份 + 记忆库 + NCE）、ISIF（增强对 + batch 内实时特征 + 两项 softmax）、CMC（多视角 + 互信息）。它们已有对比骨架，但正样本定义、损失命名、负样本来源还不是后来定型的标准形式。

## 总结：只要没有“大量显式负样本 + InfoNCE / NT-Xent + 训练编码器”这三件套，就不能叫狭义的标准对比学习

# 2. 用对比学习的方式解释一下感知损失变体，对于这个预训练模型来说，什么是正样本？什么是负样本？

## 解释一下感知损失变体

- 预训练模型和中间层**与感知损失完全相同**：VGG19 的 `features[:35]`，ImageNet 均值、标准差归一化。
- VGG 参数全部 `requires_grad = False`，且固定 `eval()` 模式。
- 每张图先过 VGG 得特征图 (B, 512, H, W)，再经 `AdaptiveAvgPool2d((1,1))` 压成 (B, 512, 1, 1)，摊平成 (B, 512) 向量。**空间信息在这一步被平均掉了**，只剩每通道的全局平均。
- `forward(input_image, generated, ground_truth)`：三路走同一条流水线，各得一条向量；`sim_pos = cosine(vec_gen, vec_gt)`（想让它大），`sim_neg = cosine(vec_gen, vec_input)`（想让它小）；`loss = (1.0 − sim_pos) + sim_neg`，再对 batch 取 mean。

## 对于这个预训练模型来说，什么是正样本？什么是负样本？

| 对比学习概念 | 在任务变体里的对应物 | 为什么是它 |
| --- | --- | --- |
| **正样本（positive）** | **无雨目标 ground_truth（vec_gt）** | 同一场景的干净真值。目标是让预测在 VGG 特征方向上靠近它，sim_pos → 1 时 (1 − sim_pos) → 0。 |
| **负样本（negative）** | **有雨输入 input_image（vec_input）** | 同一场景的退化版本。目标是让预测在特征方向上远离它，sim_neg 越小越好。 |
